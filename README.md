📌 Project Description

The Retail Sales Forecasting & Inventory Optimization System is a Python-based data science project designed to forecast future retail demand and optimize inventory management using machine learning and virtual simulation.

The system uses synthetic retail sales data, data preprocessing, exploratory data analysis, and a Random Forest Regressor to predict product demand. It calculates safety stock, reorder points, and recommended order quantities to help identify potential stockouts and excess inventory.

An interactive Streamlit dashboard presents sales trends, demand forecasts, inventory alerts, and downloadable reports.

Tech Stack: Python, Pandas, NumPy, Scikit-learn, Matplotlib, Streamlit.

Objective: To demonstrate practical skills in machine learning, retail analytics, demand forecasting, inventory planning, and business intelligence for internship and placement opportunities.

Note: This project uses synthetic data for educational and portfolio purposes. It is not connected to real retail company systems.
